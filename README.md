🦠 COVID‑19 Infection Rate & Life‑Factors Analysis
A data‑driven exploration of how COVID‑19 infection rates relate to country‑level life‑quality indicators. This project applies correlation analysis techniques to examine relationships between maximum infection rates and factors such as GDP per capita, social support, healthy life expectancy, and freedom to make life choices.

🔍 Project Overview
The goal of this analysis is to calculate each country’s maximum infection rate using daily confirmed case data and investigate how these rates correlate with key life‑quality variables from the World Happiness Report. By joining the datasets and analyzing numeric features, the project highlights patterns that reveal how socioeconomic conditions may influence the spread of COVID‑19.
